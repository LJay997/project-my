**滴滴面试通常分为3轮（技术一面→技术二面→HR面），核心考察项目深挖、Java基础与并发、中间件原理、数据库、分布式系统设计、算法手撕及AI项目经验。**

### 面试流程概览
- **一面（约50-90分钟）**：基础功底 + 项目深挖，题量大、节奏快，考察"够不够硬"
- **二面（约50分钟）**：系统设计 + 工程思维 + 场景题，考察"适不适合团队方向"
- **HR面（约30分钟）**：职业规划、优缺点、项目难点、工作生活平衡

### 一面高频题（基础 + 项目）

#### Java 基础与并发
- HashMap 底层实现？为什么数组长度是 2 的 n 次幂？
- ConcurrentHashMap 的实现原理？JDK 7 和 JDK 8 的区别？
- CAS 是什么？ABA 问题怎么解决？
- AQS 原理？公平锁和非公平锁怎么实现？
- Synchronized 和 ReentrantLock 的区别及各自实现原理？
- Java 内存模型 JMM 有哪些区？Volatile 关键字的作用和实现原理？
- 线程池怎么配置？用了什么队列？为什么？

#### Redis
- Redis 5 种基本数据类型 + 3 种扩展类型？
- Redis 为什么快？（内存、I/O 多路复用、单线程、高效数据结构）
- Redis 分布式锁怎么设计？看门狗机制？
- Redis Lua 脚本的使用场景？（如秒杀预扣库存）
- 缓存穿透、缓存击穿、缓存雪崩怎么解决？
- 持久化机制？AOF 重写策略？

#### MySQL
- B+ 树索引和哈希索引的区别？
- 什么情况下索引会失效？
- 事务隔离级别有哪些？默认是哪个？
- 幻读是什么？可重复读级别下会有幻读吗？
- MVCC 原理？解决了什么问题？
- MySQL 锁有哪些？

#### 分布式与中间件
- 分库分表怎么设计？按什么维度分？
- Kafka 高性能的原因？延迟队列怎么实现？
- 滑动窗口限流怎么设计？Redis 里存什么？
- 数据库和 Redis 的一致性怎么保证？
- 秒杀场景如何保证原子扣减和库存一致性？会不会超卖？
- 幂等性怎么实现？

#### 算法手撕（必考）
常见题型包括：
- 反转链表 / 反转区间链表
- 合并区间
- LRU 缓存（要求 get/put 都是 O(1)）
- 环形链表
- 快速排序
- 和大于等于目标值的最短连续子数组
- 兑换零钱（动态规划）

### 二面高频题（系统设计 + 场景题）

二面更侧重**工程思维和业务理解**，典型问题：

- **场景设计题**：优惠券既可以秒杀又可以正常售卖，怎么设计？（据面经反馈这是整场最难的问题）
- **项目重构**：如果让你重新做这个项目，你会改变哪些决策？
- **技术选型**：为什么选这个方案而不是其他方案？
- **线上问题排查**：项目中遇到过内存泄漏或崩溃吗？怎么定位和解决的？
- **系统设计**：设计一个系统需要考虑哪些方面？跟外部合作需要考虑什么？
- **AI 相关**：记忆系统怎么实现？短期记忆和长期记忆怎么配合？RAG 知识库怎么做的？为什么用混合检索？

### 2026 年新增考察方向：AI 项目经验

从最新面经来看，滴滴（尤其是花小猪等业务线）开始重点考察候选人的 **AI 工程化能力**：

- 你项目中的 AI Code Review 提示词是怎么做的？
- 智能问答知识库的长短期记忆怎么实现？
- 向量数据库是本地还是集群？多知识库之间怎么同步？
- 有没有用过 Agent？Codex、Claude Code 的记忆机制了解吗？
- 线上缺陷率下降 60% 这个数据怎么来的？

### 面试风格总结

| 维度 | 特点 |
| :--- | :--- |
| **广度** | 一面题量大，几乎把 Java 基础、Redis、MySQL、中间件全扫一遍 |
| **深度** | 不停留在"是什么"，会追问"为什么"和"底层怎么实现" |
| **项目** | 会顺着你的项目一直深挖，细节不熟很容易卡住 |
| **场景** | 二面喜欢出开放性场景题，考察设计能力和权衡取舍 |
| **手撕** | 每轮基本都有算法题，难度中等偏上 |

### 备考建议

- **基础八股要扎实**：不是背答案，要能讲清"为什么"，面试官会一直追问到底
- **项目要能讲透**：每个模块的技术选型、设计思路、踩过的坑都要能结构化表达
- **算法保持手感**：LeetCode Hot 100 刷一遍，重点练链表、动态规划、滑动窗口
- **了解滴滴业务**：网约车定价策略、智能调度、共享出行竞争格局等，面试中可能会涉及
- **准备 AI 项目经验**：如果有 RAG、Agent、智能问答等项目，准备好技术细节和量化成果

> 一句话总结：滴滴面试的核心风格是**"基础要硬、项目要深、场景要活"**，不是纯背八股就能过的，需要把每个知识点和自己的真实项目经验串起来回答。
